# Каталог запчастей и VIN-декодер

Сборка предназначена для локального запуска на Mac и для последующей интеграции с сайтом. В форме поиска автомобиля одно поле для 17-символьного VIN и японского номера кузова. Расшифровка обычных VIN через локальные базы работает без интернета. Для номеров кузова используется публичный API VINROKU. Для запчастей доступны кроссы FAPI, каталог Autodoc и объявления Car-Part.

## Запуск на Mac

Из папки с `proxy.py` можно запустить сборку этими командами.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python proxy.py --port 8010
```

Откройте [http://127.0.0.1:8010/](http://127.0.0.1:8010/). Порт 8010 позволяет запустить сборку рядом с текущим сайтом на 8000 и прокси на 8001. Для подключения каталога задайте `REEF_KEY` и `APIFY_TOKEN` в локальном `.env` рядом с `proxy.py`. Шаблон параметров находится в `.env.example`. При временном токене задайте `APIFY_TOKEN_EXPIRES_AT` в формате ISO 8601 с часовым поясом. Этот срок проверяет приложение.

Для работы в прежней схеме с двумя процессами статический сервер на порту 8000 должен отдавать только публичный `index.html` из отдельной папки. Прокси по умолчанию слушает порт 8001. Встроенный сервер отдаёт только `/` и `/index.html` и умеет обслуживать API с того же адреса. После изменения Python-кода или ключей в `.env` перезапустите прокси.

## API для интеграции

Запросы `POST` используют `Content-Type: application/json`.

| Метод и маршрут | Входные поля | Результат |
| --- | --- | --- |
| `POST /vin` | `vin` с VIN или номером кузова | Для VIN возвращаются WMI, `status`, `source`, `vehicle` и предупреждения. Для номера кузова возвращается `type: "chassis"` с результатами по серийным диапазонам, справочником моделей или ответом резерва |
| `POST /vin/check-digit` | `vin` с имеющимся символом или `?` в позиции 9 | Вычисленный символ США, результат сравнения, VIN с вычисленным символом |
| `POST /autodoc` | `query`, `mode` (`part`, `keyword`, `oe`), `market`, `page`, `max_results` | Цены и предложения ReefAPI. При повторе из кеша `meta.cached=true` и `meta.charged_credits=0`. |
| `POST /fapi/part` | `article`, необязательно `manufacturer_id` | Карточка с аналогами, оригинальными номерами OE и заменами. При одинаковом артикуле у нескольких брендов возвращает список кандидатов. |
| `POST /fapi/vehicle-parts` | `query`, необязательно `choices` | Справочные номера Probox или подбор FAPI с выбором модели, модификации и группы деталей. Для продолжения передайте прежний запрос и объект `choices` из ответа, добавив в него выбранный ID под именем `field`. |
| `POST /parts/search` | `query`, необязательно `choices` и `confirmed` | Подбор из формы. Сначала разбирает запрос локально. Для статуса `confirm` повторите его с `confirmed: true`. Для статуса `choose` добавьте выбранный ID под именем `field` в возвращённый объект `choices`. Статус `article` возвращает проверенный артикул для `/fapi/part`. |
| `GET /fapi/usage` | — | Тариф, состояние доступа и последний остаток каталожных кредитов от FAPI |
| `POST /parts/ai-suggest` | `query` | Предложенная фраза для поиска или просьба уточнить деталь или автомобиль |
| `POST /car-part` | `year`, `makeModel`, `part`, `userZip` | HTTP 202 и `run_id` |
| `POST /car-part/status` | `run_id` | HTTP 202 во время поиска, HTTP 200 с массивом `items` после завершения |
| `GET /api-providers` | — | Реестр API с назначением, статусом настроек и доступными сведениями о лимитах |

Для VIN маршрут `/vin` возвращает HTTP 200 со статусом `decoded`, `partial` или `no_data`. `partial` означает, что доступна только часть полей или источник сообщил об ограничениях. HTTP 400 означает ошибку входных данных. HTTP 503 означает, что vPIC недоступен и локальный справочник не смог опознать автомобиль. В `vehicle` присутствуют только доступные поля. Модельный год передаётся отдельно от списка возможных лет. `check_digit` принимает значения `match`, `mismatch` или `not_assessed`.

Для LADA используется локальный `vininfo`. Для рынка США по умолчанию применяется снимок NHTSA vPIC, встроенный в `ultravin`. В сборке зафиксирована версия базы через зависимость `ultravin==3.0.2`. При выборе `VIN_VPIC_MODE=online` запросы, которые не удалось полностью расшифровать как LADA, отправляются в публичный API NHTSA. Для расширения покрытия можно подключить поставщика данных в `vin_decoder.py`, сохранив формат `/vin`. При полной расшифровке из vPIC интерфейс позволяет подставить марку, модель и год в форму Car-Part. Поиск запускается отдельной кнопкой.

Японский номер передаётся в VINROKU с исходными нулями серийной части. API отвечает совпадениями по диапазонам и отдельно справочными конфигурациями. Для `MXPH14-0036630` диапазоны дают возможные годы выпуска 2024 и 2025, а каталог указывает Toyota Yaris. Серийные совпадения показываются со ссылкой и страницей документа, когда источник их передаёт. Лимит составляет 100 запросов за сутки UTC на сетевой адрес сервера. Приложение кеширует повторные запросы на один час и записывает последнее значение квоты из заголовков VINROKU. [Документация VINROKU](https://vinroku.jp/api-docs).

При заданных `API_NINJAS_KEY` и `API_NINJAS_MODE=demo` API Ninjas используется для локальной проверки VIN без модели или номера кузова без результата VINROKU. Источник также может подхватить запрос при ошибке VINROKU. Приложение использует ответ, если API вернул производителя и модель. Эти поля требуют Premium. Для коммерческого сайта режим `commercial` применим с соответствующим платным тарифом. По умолчанию режим `off`. Ответы API Ninjas используются только для текущего запроса. [VIN Lookup](https://api-ninjas.com/api/vinlookup) и [тарифы API Ninjas](https://api-ninjas.com/pricing).

Car-Part запускает Actor Apify `YJtKnjFupdQDdpN05` с лимитом 25 объявлений и трёх страниц. Одинаковый поиск повторно использует идентификатор запуска в течение семи минут после создания. Цена объявления отражает данные разборки. Совместимость детали следует сверять по каталожному номеру и модификации автомобиля. [Описание Actor и формата объявлений](https://apify.com/crawloop/car-part-scraper).

## Подбор запчастей и бюджет FAPI

Поле «Деталь и машина или артикул» принимает запросы в произвольном порядке, например «фильтр маслянных пробокс», «масляный фильтр Camry 2019 2,5» и «vfckzysq abkmnh ghj,jrc». Приложение распознаёт распространённые написания, опечатки и путаницу между русской и английской раскладками. Для масляного фильтра Probox посетитель выбирает двигатель и при необходимости кузов либо месяц выпуска. Можно сразу дописать код кузова, например `NSP160V`. Справочник Probox и выбор двигателя работают локально за 0 кредитов. [Таблица применимости DENSO](https://am.denso.com/search/sof/soundList.cgi?Line=5&maker=01toyota) и [схема Toyota EPC](https://toyotaepc.com/toyota/probox-succeed/JP/oil-filter).

Для остальных машин посетитель подтверждает распознанную фразу перед первым платным обращением. Если человек ввёл год, объём или код двигателя, варианты сужаются до подходящих значений из каталога. Для поиска по артикулу, кнопки «Аналоги» и подбора по другим автомобилям задайте `FAPI_KEY` действующего пакета в локальном `.env`. Текстовый поиск покрывает распространённые группы деталей, включая фильтры, тормозные колодки и диски, свечи, амортизаторы и щётки стеклоочистителя. Если артикул встречается у нескольких брендов, выбор бренда требует отдельной карточки.

Новая карточка стоит 1 кредит. Полный подбор с пустым кешем стоит до 35 кредитов: марки 3, модели, модификации, узлы и детали узла по 8. Остаток проверяется бесплатно. Повторные запросы разделяют SQLite-кеш в `fapi-state.sqlite3` на одном сервере. На активном оплаченном доступе с известным сроком справочники марок, моделей, модификаций и узлов сохраняются до 7 дней, результаты деталей и кроссов — до суток, пробные ответы — до 5 минут. Кеш ограничен сроком действия пакета. Лимит `FAPI_DAILY_CREDIT_LIMIT` по умолчанию составляет 1 000 кредитов за сутки по Москве. Учёт проверяет максимальную стоимость перед запросом и учитывает подтверждённый пустой ответ как 1 кредит. [Документация](https://fapi-dev.github.io/catalog-openapi/) и [тариф](https://fapi.iisis.ru/api-dostup).

## Уточнение запроса с Groq

Кнопка «Уточнить запрос с ИИ» в панели источников отправляет введённую фразу в Groq. Для неё задайте `GROQ_API_KEY` в локальном `.env`. Системный промпт находится в `part_ai.py`. Он выделяет тип детали, марку и модель. Приложение проверяет ответ и предлагает подтвердить новую фразу перед поиском. На сервере действует отдельный лимит `GROQ_DAILY_REQUEST_LIMIT` с исходным значением 50 подсказок за сутки по Москве. [Структурированный ответ Groq](https://console.groq.com/docs/structured-outputs).

## Локальный каталог магазина

Импортируйте выгрузку АН‑30 или поставщика, разрешившего использовать данные в магазине. Подбор по импортированным строкам выполняется локально. Установите `FAPI_FITMENT_ENABLED=0`, чтобы оставить FAPI только для артикулов и кроссов. По умолчанию резервный подбор FAPI включён. Файл `an30-fitment.sqlite3` создаётся импортом. Можно задать собственный путь через `AN30_FITMENT_DB`.

```bash
.venv/bin/python local_fitment.py /path/to/fitment.csv
```

Первая строка CSV содержит эти поля в заданном порядке.

```csv
make,model,category,configuration,engine,liters,year_from,year_to,article,brand,oem,source
```

Файл записывается в UTF‑8. Артикул сохраняется строкой, включая ведущие нули. `category` берётся из `CATEGORIES` в `vehicle_parts.py`. `configuration` должна различать кузов, период или другие существенные условия установки. `oem` равно `1` для номера производителя автомобиля и `0` для aftermarket. В `source` укажите происхождение данных. Импорт заменяет содержимое местного каталога целиком в одной транзакции. Неполный либо ошибочный файл отменяет замену.

Autodoc принимает названия деталей в форме и приводит распознанные категории к языку витрины UK, DE или ES. Запрос с автомобилем сначала идёт через выбор модификации. После подбора кнопка «Цены в Autodoc» использует артикул или исходный номер OE. Цены запрашиваются отдельно по действию пользователя. [ReefAPI Autodoc](https://reefapi.com/docs/autodoc).

## Реестр API

Панель «Источники данных и лимиты API» показывает записи из `api-providers.sqlite3`. В базе хранится название переменной для ключа. Значения ключей находятся в локальном `.env` с правами `0600`. Панель показывает наличие ключа и локальный срок тестового доступа Apify. Для Firecrawl, Corgi и Cardog внесены адреса и ограничения для дальнейшей проверки.

```bash
sqlite3 -header -column api-providers.sqlite3 'SELECT name, allowance, credential_env FROM providers;'
```

## Проверка

```bash
.venv/bin/python -m unittest -v
```

Тесты используют установленные базы для `XTAGFK330JY144213` (LADA Vesta, модельный 2018 год, двигатель 21179, Ижевск) и `1HGCM82633A004352` (Honda Accord EX‑V6, модельный 2003 год, 240 hp, АКПП на пять передач). Онлайн-провайдеры в тестах используют подставные ответы. Проверяются неоднозначные совпадения VINROKU, отказ при исчерпанной квоте, отсутствие ключей в ответе реестра, резерв API Ninjas, CORS и кеш ReefAPI.
