# Посты и сообщения клиентов АН30

Раздел **Посты и мессенджеры** в рабочем месте делает две вещи:

- **Публикации.** Пост пишется один раз и уходит во все площадки, где включено «Публиковать посты»: канал Telegram, канал MAX, стена сообщества ВКонтакте (с фото). Исправленный пост редактируется на площадках, а не публикуется заново.
- **Входящие.** Сообщения, которые клиенты пишут боту Telegram, боту MAX и сообществу ВКонтакте, приходят в «Входящие». Ответ менеджера уходит клиенту в тот же чат.

| Площадка | Посты | Сообщения клиентов |
| --- | --- | --- |
| Telegram | Канал, где бот — администратор | Личные сообщения боту |
| MAX | Канал, где бот — администратор | Личные сообщения боту |
| ВКонтакте | Стена сообщества, текст и фото | Сообщения сообщества |
| WhatsApp | Только вручную: сайт создаёт задачу и даёт скопировать текст | WhatsApp Business, в течение 24 часов после сообщения клиента |

## Перед началом

- Подключение делается на **рабочем сайте** (адрес `https://…` без номера порта). На тестовой копии сайта настоящие отправки выключены — там используйте «Тестовый режим».
- Подключает администратор: **Посты и мессенджеры → Площадки → Подключить площадку**. В окне есть пошаговая подсказка для каждой площадки.
- После сохранения сайт сразу выполняет **«Проверить»** и показывает результат на карточке: «Работает», «Нужно внимание» (у каждой строки написано, что сделать) или «Не проверено». Проверка ничего не публикует и не меняет настройки бота.
- Секретный ключ для сообщений создаётся автоматически. Для Telegram и MAX сайт передаёт его сам, для ВКонтакте его нужно один раз скопировать.

## Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` (или выберите существующего бота) и скопируйте токен вида `123456789:AA…`.
2. Добавьте бота в канал АН30 **администратором** с правами «Публикация сообщений» и «Редактирование сообщений».
3. В АН30: площадка **Telegram**, вставьте **Токен бота**, в **Канал для постов** укажите `@an30_autoparts` (или ссылку `https://t.me/…`). Отметьте «Публиковать посты» и «Принимать сообщения клиентов», снимите «Тестовый режим», сохраните.
4. На карточке нажмите **Подключить обращения**. Если бот уже отвечает клиентам через другой сервис, сайт попросит подтвердить перенос.
5. Напишите боту из личного аккаунта — сообщение появится во «Входящих».

Ограничение Telegram: к опубликованному текстовому посту нельзя добавить фото, а из поста с фото нельзя убрать фото. Сайт предупредит об этом в окне редактирования до сохранения и сообщит на карточке поста; чтобы фото появилось в Telegram, опубликуйте новый пост.

## MAX

1. В кабинете MAX для партнёров ([business.max.ru](https://business.max.ru)) создайте бота или откройте существующего и скопируйте токен в разделе интеграции.
2. В АН30: площадка **MAX**, вставьте **Токен бота**, отметьте «Принимать сообщения клиентов», снимите «Тестовый режим», сохраните. ID бота сайт определит сам.
3. На карточке нажмите **Подключить обращения**.
4. Добавьте бота **администратором** канала АН30 в MAX и нажмите **Проверить** — на карточке появится строка «Бот добавлен в каналы» с ID канала. (MAX не даёт боту список каналов, ID приходит, когда бота добавляют в канал, поэтому сначала нужен шаг 3.)
5. **Настроить** → вставьте этот ID в **ID канала MAX для постов**, отметьте «Публиковать посты», сохраните.

## ВКонтакте

1. В сообществе: **Управление → Сообщения** — включите сообщения сообщества.
2. **Управление → Работа с API → Ключи доступа** — создайте ключ с правом «Сообщения сообщества». В АН30 вставьте его в **Ключ доступа сообщества**. ID сообщества и стены сайт определит по ключу.
3. Для постов на стене нужен ещё **токен администратора** с правами `wall` и `photos` (ключ сообщества публиковать на стене не умеет). Его один раз получает разработчик через приложение ВКонтакте; вставьте в **Токен администратора для постов на стене**. Без него работают только сообщения — не отмечайте «Публиковать посты».
4. **Работа с API → Callback API**: скопируйте строку из «Строка, которую должен вернуть сервер» в поле **Строка подтверждения из Callback API**. Снимите «Тестовый режим», сохраните.
5. На карточке ВКонтакте скопируйте **Адрес для Callback API**. В ВК в Callback API вставьте адрес, в «Секретный ключ» — секрет (кнопка **Копировать для ВК** в окне «Настроить»), нажмите **Подтвердить**. В «Типах событий» отметьте «Входящее сообщение» (и при желании «Редактирование сообщения»).
6. Напишите сообществу со своего аккаунта и нажмите **Проверить**: пока ВК не прислал ни одного события, карточка подскажет, что проверить.

## Статусы и что делать

- **В очереди / Отправляется** — ждать. Ограничения частоты площадок сайт соблюдает сам и повторяет отправку.
- **Отправлено** — площадка приняла пост или ответ.
- **Ошибка** — площадка отказала (токен, права, клиент заблокировал бота). Причина написана рядом. Исправьте и нажмите «Повторить». Если Telegram не может добавить или убрать фото, вместо «Повторить» стоит «Изменить пост»: повтор дал бы ту же ошибку.
- **Нужна проверка** — площадка не ответила, и неизвестно, появился ли пост или ответ. Откройте площадку: если пост есть — выберите «Пост есть — сохранить его ID» и вставьте ссылку на него (Telegram: нажать на пост → «Копировать ссылку»; ВКонтакте: адрес записи на стене) или его номер; если нет — повторите. Ссылку на пост другого канала сайт не примет. Пока проверка не сделана, следующие версии этого поста на этой площадке ждут, чтобы не было дублей. Правки постов и отправки ВКонтакте (у ВК есть защита от повторов) сайт повторяет сам.

У отправленного поста в Telegram и ВКонтакте на карточке есть ссылка **«Открыть пост»** — она ведёт на сам пост на площадке (для закрытого канала Telegram открывается только у его участников). У MAX адреса поста нет.

## Сообщения клиентов

Сотрудник включает «Принимать обращения» в верхней панели. Пока вкладка открыта, сайт назначает новые обращения доступным сотрудникам по очереди; клиенту в мессенджер приходит «Менеджер … подключился». До назначения бот здоровается и отвечает только утверждёнными автоответами (раздел «Автоответы»); вопросы о цене, наличии и подборе всегда передаются менеджеру. Вложения из мессенджеров отмечаются в истории по типу — открыть их можно в самом мессенджере.

## Проверка без настоящих площадок (для разработчиков)

API и worker умеют работать с локальным имитатором площадок: `HUB_PROVIDER_EMULATOR_URL=http://127.0.0.1:<порт>` направляет все вызовы Telegram/MAX/VK на него (пути `/telegram/bot<token>/<method>`, `/max/…`, `/vk/method/…`, загрузка фото ВК `/vk-upload/…`, картинки `/images/<host><path>`). Тогда «рабочие» подключения разрешены и вне production. В production эта переменная запрещена — сервис не запустится.

Сам имитатор — `scripts/client-hub-checks/provider-emulator.mjs`; как запустить стенд с ним, как вызвать отказ или потерю ответа площадки и что проверяется в CI — `scripts/client-hub-checks/README.md`.

Используемые методы: Telegram Bot API — `getMe`, `getChat`, `getChatMember`, `getWebhookInfo`, `setWebhook` (`secret_token` → заголовок `X-Telegram-Bot-Api-Secret-Token`), `sendMessage`/`sendPhoto` с `entities`, `editMessageText`/`editMessageMedia`. MAX (`https://platform-api2.max.ru`, токен в заголовке `Authorization`) — `GET /me`, `GET/POST/DELETE /subscriptions` (секрет → `X-Max-Bot-Api-Secret`), `POST /messages?chat_id|user_id`, `PUT /messages?message_id`, `GET /chats/{id}/members/me`. VK API 5.199 — `wall.post` (`guid`), `wall.edit` (ответ `{post_id}`), `photos.getWallUploadServer` → загрузка → `photos.saveWallPhoto`, `messages.send` (`random_id`), `groups.getById`, `account.getAppPermissions`; Callback API отвечает строкой `ok`.
