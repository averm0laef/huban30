# Ротация legacy-секретов перед запуском

Дата составления: 2026-07-31, Asia/Chita.

Удаление значения из исходников не делает ранее использованный секрет безопасным. Владелец должен отозвать или заменить каждый пункт в панели соответствующего сервиса. Новые значения нельзя отправлять в этот репозиторий или обычный чат.

## Обязательный чек-лист владельца

| Секрет | Где заменить | Состояние |
| --- | --- | --- |
| Пароль прежнего super-admin | Supabase Auth и все места повторного использования | Требуется действие владельца |
| Supabase anon/publishable key | Supabase project API settings | Требуется перед cutover |
| Supabase service-role key | Supabase project API settings и Edge Function secrets | Требуется перед cutover |
| Пароль или token обмена 1С | 1С, `store_settings` и будущий Compose secret | Требуется до следующей выгрузки |
| Telegram bot token | BotFather и Edge Function secrets | Требуется, если бот использовался |
| VK client secret | VK ID application settings | Требуется, если вход VK использовался |
| SMTP/Resend key | Панель почтового провайдера | Требуется, если ключ существовал |
| Lovable AI key | Lovable project secrets | Отозвать после подтверждения, что legacy AI не нужен |
| Ключи эквайринга и webhook | Панель выбранного провайдера | Ещё не выдавались |

## После каждой ротации

1. Записать дату и исполнителя без самого секрета.
2. Проверить, что старое значение отклоняется.
3. Подключить новое значение через root-only файл или secrets провайдера.
4. Проверить логи на отсутствие значения и персональных данных.
5. Выполнить минимальный smoke-тест затронутой интеграции.

## Временные ограничения legacy

- AI, VIN lookup, поиск изображений, Telegram/VK auth, custom magic-link, Telegram webhook/notifications и публичное создание администратора отвечают `410 Gone`.
- Legacy 1С принимает запросы только с IP из `ONE_C_ALLOWED_IPS` и требует аутентификацию на каждом запросе.
- Разрешённые browser origins задаются `LEGACY_ALLOWED_ORIGINS`; значение по умолчанию содержит только `an30.ru` и `www.an30.ru`.
- Старый Supabase-проект не удалён и не будет удалён без отдельного подтверждения.
