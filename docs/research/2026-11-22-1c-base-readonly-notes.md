  Автошины легковые, Автошины грузовые. То есть «Категории номенклатуры» почти не ведутся — раскладывать по ним нельзя.

- Названия — короткие, с типом детали в начале: «Предохранитель», «Пыльник силиконовый», «Шайба простая М5»,
  «Гровер D-16 Белзан», «Заклепка тормозная 10*22», «Клипса обшивы двери ВАЗ…», «Набор саморезов с полукр…».

- **Поле «Описание» содержит внутренние заметки**: «АУДИТ 17.07.2025 -943ШТ», «аудит 06 11 2025 +80шт»,

## Происшествие при сохранении файла (22.11.2026, 05:25–05:33) — что случилось и что исправлено

Когда я вводил имя файла в системном окне «Сохранить», мой вспомогательный инструмент отправил буквы с «зажатой» клавишей Command
(ошибка инструмента: признак Command остался от предыдущей команды «выделить всё»). Последствия:

1. В окне сохранения сработали сочетания клавиш вместо ввода текста; одно из них («показать в Finder») открыло окно Finder
   с домашней папкой. Окно я закрыл. Finder при этом сам записал служебные файлы вида `.DS_Store` в подпапки «Документов»
   (curseforge, Roblox, VPN, Codex) — это его настройки отображения папок. Пользовательские файлы не менялись: проверено,
   изменённых файлов, кроме `.DS_Store`, в «Документах» нет, в Корзине ничего нового.
2. Появились два системных запроса доступа: «Devin → Apple Music/медиатека» (его вызвала моя слишком широкая команда поиска по домашней папке)
   и «1С → папка Документы». На оба я нажал «Не разрешать», затем вернул оба решения в состояние «не решено» (`tccutil reset`),
   чтобы решение принимал владелец. Файл при этом сохранился (окно сохранения даёт доступ к выбранному файлу само).
3. **В базе 1С ничего не изменилось**: всё это время было открыто системное окно сохранения файла, окна и вкладки 1С остались прежними.

Исправление инструмента: из него убраны ввод текста и любые сочетания клавиш; каждое событие отправляется с явно пустыми модификаторами;
оставлены только щелчок, прокрутка и клавиши навигации (Esc, стрелки, PageUp/PageDown, Home/End). Имя файла теперь не набирается:
файл сохраняется под именем по умолчанию и переименовывается уже на диске.

## Виды цен (Продажи → Виды цен)

В базе всего два вида цен: **«Оптовая цена»** и **«Учетная цена»** (оба статические, с НДС). Розничного вида цен нет.
Значит «Оптовая цена» — это и есть цена продажи магазина; её и нужно выгружать на сайт (как сейчас в старой настройке).
«Учетная цена» — себестоимость, на сайт попадать не должна ни при каких условиях.
**Это отменяет моё прежнее предупреждение** «в узле выбрана оптовая цена, сайт опубликует оптовые цены»: предупреждение было неверным для этой базы.

## Карточка номенклатуры (открыта на просмотр и закрыта без записи)
