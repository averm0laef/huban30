## Кабинеты ролей — что нужно

На production нет ни одной учётной записи (`app.users` — 0), почта выключена (`SMTP_ENABLED=false`).
- **admin (владелец):** `create-owner.js` в контейнере API (docs/AUTHENTICATION.md), пароль — файлом через stdin. Пароль придумывает владелец (агенту задавать пароли нельзя): файл `secrets/owner_password.txt`, адрес почты владельца. После первого входа — настройка TOTP на телефоне.
- **manager, director:** только приглашением от admin по почте → нужен SMTP (Яндекс Postbox).
- **customer:** регистрация с подтверждением по почте → тоже SMTP; регистрация на сайте закрыта до утверждения юридических текстов (docs/DEPLOY_VPS.md).
