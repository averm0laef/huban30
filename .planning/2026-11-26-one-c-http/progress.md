# Обмен с 1С, 26 ноября 2026

На снимке основной базы 401 относится к выключенному обмену, позднее видны 429 на входе и передаче файла. В 1С владелец видел 201. Связь между 201 и повторами запросов по этому журналу установить нельзя.

В изолированной копии локального main (8fb740d) на собранном контроллере NestJS с Fastify и тестовыми зависимостями воспроизведена успешная загрузка части файла с HTTP 201 для обеих баз. После исправления POST того же файла вернул HTTP 200 и текст success. Проверка обмена в CLI теперь требует ровно 200. При превышении лимита клиенту возвращается 429 и Retry-After на 60 секунд. Недоступность проверки лимита даёт 503. Пороги и окна сохраняют прежние значения.

Прошли HTTP-проверки 200, 401, 429 и 503 на обоих маршрутах, все 35 тестов контроллера, lint, typecheck и сборки API и сайта. Общий pnpm test остановился в трёх наборах API, которым требуется открыть локальный порт (S3, ClamAV, проверка медиа). Среда запрещает listen на 127.0.0.1. Локальная ссылка origin/main совпадала с HEAD, обновить её с GitHub из среды не удалось. На боевой сайт изменения не выкладывались. Сквозная выгрузка из базы владельца остаётся для проверки после выпуска.
