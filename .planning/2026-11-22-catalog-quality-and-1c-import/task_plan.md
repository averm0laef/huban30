## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Дерево разделов у сайта своё; дерево 1С не копируется | группы 1С — по технике, поставщикам, годам; часть товаров без группы |
| Неверная полка хуже очереди: словарь отвечает «не знаю» | ошибку в очереди видит сотрудник, ошибку на полке — покупатель |
| Артикул — не ключ товара (миграция 0046) | в базе владельца десятки товаров делят один артикул |
| На сайт идёт один вид цен; себестоимость ценой не становится | в базе «Оптовая цена» и «Учетная цена» |
| «Описание» из 1С по умолчанию не публикуется | там внутренние пометки |
| Сайт сам товары не прячет; скрытую полку назначает сотрудник | спрятанный по ошибке товар — незаметная потеря продажи |
| Название-работа автоматически не раскладывается | прайс СТО лежит среди товаров |
| Оригинальный номер спрашивается последним, только коды с согласием ≥ 95 % на ≥ 8 товарах | код детали бывает неоднозначным (90919) |
